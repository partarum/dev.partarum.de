**/controllers/** *(Logik zur Verarbeitung von Anfragen)*
*   Enthält Klassen, die eingehende Anfragen verarbeiten.
*   Jeder Controller ist typischerweise für einen bestimmten Bereich der Anwendung zuständig (z.B. Benutzerverwaltung, Produktkatalog, Warenkorb).
*   Die Controller-Methoden enthalten die Logik, um Daten abzurufen, zu verarbeiten und an die Views zu übergeben.
*   Beispiel: `UserController.php`, `ProductController.php`
