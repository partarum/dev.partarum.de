**/views/** *(Templates zur Darstellung der Daten)*
*   Enthält Dateien, die die HTML-Struktur und die Darstellung der Daten definieren.
*   Oftmals werden Template-Engines wie Twig oder Blade verwendet, um dynamische Inhalte in die HTML-Struktur einzufügen.
*   Die Views erhalten Daten von den Controllern und geben formatierten HTML-Code aus.
*   Beispiel: `user/profile.php`, `product/details.php`
