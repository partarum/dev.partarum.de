**/core/** (oder **/shared** / **/common**) *(Gemeinsame Funktionen und Komponenten)*
*   Enthält Code, der von mehreren Modulen oder der gesamten Anwendung genutzt wird.
*   Beispiele:
*   **/auth/**: Authentifizierungs- und Autorisierungslogik.
*   **/components/**: Wiederverwendbare UI-Komponenten, die nicht spezifisch für ein Layout sind.
*   **/services/**: Logik, die von verschiedenen Controllern oder Modulen verwendet wird (z.B. E-Mail-Versand, API-Integration).
*   **/utils/**: Hilfsfunktionen und -klassen (z.B. Datumsformatierung, String-Manipulation).
